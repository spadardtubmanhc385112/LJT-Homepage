# Junteng Liu - Personal Academic Homepage

This repository contains the source of Junteng Liu's personal academic website, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll theme.

## Site structure

* `_config.yml` - site-wide settings and author (sidebar) information
* `_data/navigation.yml` - links shown in the site header
* `_pages/about.md` - home page: biography, research interests, education, research experience, honors, skills, publications, and contact information
* `_pages/cv.md` - CV page
* `_pages/publications.html` - publications page, generated from the `_publications` collection
* `_publications/` - one Markdown file per publication
